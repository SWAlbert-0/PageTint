# 数据与隐私

PageTint 不提供账户、后端或云同步。扩展不包含分析、广告或主动上传标记的逻辑。

本说明涵盖商店提交版 0.9.3 与 GitHub 最新源码 0.10.1 的共同数据处理方式。下文明确标注的开关、网站规则和文章识别功能仅适用于 0.10.x；此次 GitHub 更新没有替换商店提交包。

## 本地保存的内容

- 标记涉及的原文片段、前后文及文本位置。
- 页面 URL、标题、标记 ID、创建和修改时间。
- 高亮、文字色、加粗、下划线等样式。
- 颜色偏好、最近使用的颜色及迁移校验信息。
- 0.10.x 新增：总开关，以及用户主动设置的网站启用或停用规则。

这些内容保存在当前浏览器用户配置的 `chrome.storage.local` 中。它不是加密保险箱；他人若能访问你的浏览器用户配置或导出的备份，也可能接触这些内容。卸载扩展会删除该安装的存储。

## 页面访问和导出

内容脚本在允许的 HTTP/HTTPS 网页中运行，以获取选文、恢复标记和响应用户的正文导出请求。用户可以在 Chrome 扩展详情中限制站点访问。

0.10.x 的自动识别模式会在本机检查页面的文章元数据与正文结构，以判断是否启用编辑功能；不会将识别结果、页面内容或网址发送到分类服务。总开关关闭后停止编辑和恢复，已有标记仍保留；网站手动规则保存在本机，属于完整数据备份的一部分。功能开关不会改变浏览器已经授予的网站访问权限。本机回环与开发地址固定停用，不读取正文进行文章识别，也不启用编辑或导出功能。

Markdown 和 JSON 由用户手动下载。Markdown 中的图片保留原在线地址，之后由 Obsidian 或其他阅读器加载；阅读器加载远程图片时可能连接图片所在网站，这与 PageTint 上传数据不同。

JSON 备份包含完整选文、网址和本地设置。请自行妥善保存，不要提交到公开仓库或 Issue。导入和摘要校验均在本地执行。

## 删除与迁移

数据管理按页面删除该页全部编辑记录。跨目录、跨浏览器配置或换电脑之前，请先使用完整 JSON 备份完成迁移并确认校验成功，再移除原安装。

如需反馈问题，请使用匿名化的样例与步骤，不要上传浏览器用户目录或个人完整备份。
