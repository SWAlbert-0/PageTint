选择 PageTint 的 JSON 备份，将数据导入当前扩展。

相同记录自动去重；如与已有数据冲突，会停止导入。

更换安装位置时

  1. 先备份，再停用

    在原扩展中下载备份，确认文件已保存，再停用原扩展，先不要卸载。

  2. 在新安装中导入

    从新目录加载 PageTint，打开这个页面，选择刚才保存的 JSON 文件。

  3. 确认恢复，再清理

    看到“迁移校验通过”后，刷新几篇原文章检查标记，再卸载旧安装、清理旧目录。

备份和校验均在本机完成，不上传数据。备份含选文与网址，请妥善保存。
